# Contexte @DucSocialBot

Ce dossier est le point d'entrée du projet `@DucSocialBot`.

Quand une session travaille dans ce dossier :

1. Lire `README.md` avant de répondre.
2. Regarder `images/README.md` pour le contexte visuel.
3. Ne pas redemander l'identité du bot, la niche, les plateformes ou l'hébergement : ils sont
   dans le README.
4. Ne pas inventer de chiffres : les métriques du dashboard sont des données de démonstration
   tant que l'import CSV/API n'est pas branché.
5. Ne pas modifier le profil Hermes, le dashboard Umbrel ou les fichiers de Roudy sans accord.

Résumé : bot Hermes `@DucSocialBot` (profil `social`), 4 plateformes (TikTok, Facebook,
YouTube, Instagram), dashboard sur Umbrel (`http://100.93.66.10:8788`), publication manuelle,
rendu vidéo sur le Mac. Le reste est dans `README.md`.
